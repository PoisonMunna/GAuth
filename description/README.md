# Google Authentication System

A simple and secure Google OAuth 2.0 authentication system that allows users to sign in using their Google accounts. This project demonstrates the basic flow of Google Login integration for modern web applications.

---

## Project Overview
This project shows how to implement user login with Google OAuth 2.0. After login, users can access their basic profile information such as name, email, and profile photo.

---

## Features
- **Google OAuth 2.0 Login**  
  Users can securely sign in with their Google accounts.

- 👤 **Fetch User Profile**  
  Retrieves user name, email ID, and profile picture.

- ⚡ **Fast & Lightweight**  
  Easy to implement in any modern web project.

- 🔑 **Secure Authentication Flow**  
  Uses Google’s official identity services.

- 📱 **Responsive UI**  
  Works smoothly across devices.

## Advantages
- ✔️ **Highly secure** (Google-managed authentication)
